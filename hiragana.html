📚 Reglas importantes

っ — Sokuon

La っ pequeña duplica la consonante siguiente.

がっこう → gakkō

ゃ・ゅ・ょ pequeños

Se combinan con ciertas sílabas para formar sonidos como kya, shu, cho, ryu, etc.

きょう → kyō

は como partícula

Cuando は funciona como partícula gramatical, normalmente se pronuncia "wa".

わたしは → watashi wa

へ como partícula

Cuando へ funciona como partícula de dirección, se pronuncia "e".

がっこうへ → gakkō e

を como partícula

を normalmente se pronuncia "o" en japonés moderno.

みずを → mizu o
