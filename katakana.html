El katakana es uno de los sistemas de escritura japoneses. Se utiliza especialmente para palabras extranjeras, nombres extranjeros, préstamos lingüísticos y algunos sonidos.

06. Reglas importantes

ー — Vocal larga

El símbolo ー alarga el sonido de una vocal. Ejemplo: コーヒー → kōhī.

ッ — Sokuon

El ッ pequeño indica una consonante doble. Ejemplo: ベッド → beddo.

ャ・ュ・ョ — Combinaciones

Las versiones pequeñas de ャ・ュ・ョ forman sonidos como キャ, シュ y チョ.

ン — Sonido N

ン representa el sonido nasal n y puede aparecer al final de muchas palabras.

🎯 Objetivo para N5

Primero domina los 46 katakana básicos. Después practica dakuten, handakuten, ャ・ュ・ョ, ッ y ー. Finalmente aprende las combinaciones usadas en palabras extranjeras.
